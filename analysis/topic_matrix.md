Source order uses local deck/lecture labels; durations and numbering are not comparable across courses. Topic links open the detailed citations, reading associations and qualifiers.

## Treatment qualifiers

- **offline_has_multiple_meanings** (resolved_by_separation): Baseline Model Free Prediction p.9 contrasts offline MDP planning with online RL; Silver prediction pp.49–50 uses offline for episodic update timing. Neither is equated to fixed-dataset modern offline RL.
- **forward_returns_vs_traces** (resolved_by_separation): Forward lambda returns, n-step targets, backward eligibility traces and GAE have related algebra but distinct evidence requirements. A GAE or n-step mention does not establish a backward trace implementation.
- **double_value_methods** (resolved_by_mechanism): Double Q-learning is separated from practical online-selection/target-evaluation Double DQN. Clipped double critics in SAC/TD3 are not automatically the same algorithm.
- **sac_without_entropy_variant** (source_variant_preserved): CS224R Q-learning tutorial p.40 labels its algorithm SAC but explicitly says no entropy term. The source label is retained with a qualification; full maximum-entropy treatment is not inferred from that slide.
- **ppo_off_policy_wording** (source_usage_preserved): CS234/CS224R call multiple updates on a recent trajectory batch off-policy. This is not treated as evidence that PPO supports arbitrary historical replay or fixed-data offline RL.
- **ipo_acronym_collision** (unresolved_do_not_merge): The CS224R default project p.8 cites Azar et al. and specifies a squared log-ratio margin IPO objective. Its optional reading titled IPO: Your Language Model is Secretly a Preference Classifier has a different title/authorship context. The reading is retained in the source manifest but is not merged into the project IPO topic without inspecting its method. Neither IPO is IQL.
- **gr_reinforce_vs_rloo** (resolved_by_objective): Berkeley HW4 calls its estimator GR-REINFORCE and uses group-relative advantages. It is not labeled RLOO merely because both use sample groups. CS224R project pp.8–9 explicitly defines leave-one-out averaging.
- **source_variant_sequence** (source_variants_preserved): CS234 pre-class Lecture 13 includes AlphaZero material absent from the shorter post-class L13; post-class L14 contains that material. Post-class page references govern the mapped sequence. No claim of identical variants or confirmed live timing.
- **baseline_skipped_exam_exclusions** (source_qualifications_preserved): Some Sarsa variants are marked skipped; projection/GTD and some trace-based actor-critic slides have exam exclusions. Artifact presence, taught detail and assessed content remain separate.
- **sft_dpo_domain** (resolved_by_domain): CS234 Assignment 3 applies SFT/DPO to Hopper action sequences, not LLMs. Shared objective names do not imply an LLM coding assignment.
- **alphago_zero_vs_alphazero** (partial_book_match): The book section 16.6.2 specifically treats AlphaGo Zero. It supports that component of the broader AlphaZero-style topic, not every later general AlphaZero system.
- **world_model_breadth** (source_scope_preserved): The Shane Gu guest lecture uses world model broadly. Its overview is not treated as evidence of Dreamer or MuZero algorithm coverage; latent-model instruction and named methods remain separate.
- **broad_topic_families** (components_retained): Search, hierarchical RL, diffusion/flow policies, and AWR/AWAC are family-level entries. Source phrases/claims retain concrete variants; these entries do not assert every component is taught wherever the family appears.
- **open_loop_planning_vs_mpc** (resolved_conservatively): Berkeley lecture 16 pp.4–13 develops open/closed-loop distinctions and open-loop shooting/CEM. This span alone does not establish receding-horizon execution, so it is not mapped to MPC. CS224R lecture 11 p.23 explicitly replans after one action and is mapped.
- **grouped_policy_objective_variants** (resolved_by_objective): Berkeley’s default LLM project requires GRPO, DrGRPO and GSPO with distinct normalization/clipping objectives. These receive separate IDs. PPO-style actor-critic is an optional Part 2 extension, not a required Part 1 implementation. IPO in both Berkeley and CS224R is mapped only after comparing the explicit squared-margin objective.
