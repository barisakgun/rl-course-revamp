# Deferred topics and connections for future course design

Created during Phase 3 on 2026-09-28 at the instructor's request. This is an analytical register, not a list of required additions or accepted designs for two courses. Current accepted scope remains in [topic decisions](../decisions/topic_decisions.yaml). Tentative mentions and optional reading ideas below consume no base-plan time unless explicitly allocated; they are not assessment prerequisites.

“Deferred” means detailed treatment is outside the current design. Some concepts are already present at a shallower level. Evidence links refer to the existing normalized model; an absent dedicated ID is not evidence that a reference course omitted the subject. No collection or normalization was reopened to make this register.

## Two-course possibility: preserve the idea, do not design it yet

A future **classical RL + theory** course could deepen MDPs, planning, prediction/control, stochastic estimation, approximation, continuing tasks, traces, stability and selected control connections. A subsequent **deep RL + LLMs** course could build on those foundations for deep value/policy methods, representation/memory, model-based and offline learning, reward learning and a larger LLM block.

That split is a hypothesis, not an accepted boundary. Policy gradients, function approximation, experimental design and partial observability are likely shared prerequisites; deciding which course owns them would require an explicit future design task, audience assumptions and separate time/workload budgets. Do not reserve every topic in this register for compulsory inclusion in either course.

## Explicit LSTD and IRL notes

Both are possible five-minute mentions, not default additions. The current candidate shortens BC to a high-level motivation and exposes local headroom. LSTD would connect to batch value estimation; IRL would contrast inferring rewards with imitating actions. They serve different purposes. Choosing both uses ten minutes, exceeding the first offline session's current 8.5-minute unallocated planning margin; use instructor-authorized delivery buffer or identify a displacement rather than pretending both are free. No new assignment or reading follows from either mention.
