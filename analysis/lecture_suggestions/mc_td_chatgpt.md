### Worked-example choices

**Grid, M03–M09.** Keep Bellman's lower-left `(1,1)`, upper-left `(1,2)`, lower-right `(2,1)`, upper-right terminal `(2,2)`; intended move probability 0.8, perpendicular slips 0.1 each, wall collisions stay put. Nonterminal transitions pay −0.04; goal entry pays +1 total, followed by zero continuation; γ = 0.5. Retain always-right for prediction, not the improved policy. These are environment/checking facts; learning needs only the sampled records.

Use `(1,1) → (1,1) → (1,2) → terminal`, taking right at each step, with rewards `−0.04, −0.04, +1`. Returns are `G_0 = 0.19`, `G_1 = 0.46`, `G_2 = 1`. First-visit sample-mean MC estimates `(1,1)` as 0.19; every-visit sample-mean MC gives 0.325. Neither is the true value inferred from one episode.

For M09, **reset both methods to V = 0 and explicitly switch to constant α = 0.5**. First-visit MC ends with `V(1,1) = 0.095`, `V(1,2) = 0.5`. Chronological TD changes `V(1,1)` first to −0.02, then to −0.03, and finally `V(1,2)` to 0.5. The final reward has not yet propagated back to `(1,1)` through this online TD pass. The methods share data and initialization but have different visit/update schedules; this is a mechanics example, not a fair empirical ranking. Keep every-visit constant-step arithmetic out of the live exercise.

Use the guide's `U_t`: MC uses `G_t`; TD uses `R_{t+1} + γV(S_{t+1})`; both update toward the target. Reserve `δ_t` for the TD error. No new counter notation or guide change is needed at this step.

**Driving home, M10 (O1 proposal).** Four minutes: roughly one to set the conventions, two for the first transition and one for interpretation. The book predicts positive **minutes remaining**, not reward-maximizing driving control; γ = 1, with α = 1 for the plotted full arrows. Leaving the office predicts 30; reaching the car takes 5 and predicts another 35. TD's target for the office is 40, available then; MC's is the eventual 43, available at home. The plot shows predicted **total** time while state value is time **remaining**. Announce these differences from the grid. Three minutes is plausible only with less learner response; it is not demonstrated feasible.

**Average reward, M12.** Propose a separate continuing service system with equal-duration time steps. At a ready state, a steady-service action returns 0.8 and remains ready; a large-job action returns 0 and enters a busy state, whose forced completion returns 2 and returns to ready. Two fixed policies yield `0.8, 0.8, …` and `0, 2, 0, 2, …`. Their average rewards `r(π)` are 0.8 and 1 per step. From ready, their γ = 0.5 discounted returns are 1.6 and 4/3: the objective can change the ranking. Allow 1 minute for setup, 2 for rates, 1 for the discounted comparison, 1 for discussion. This is an objective illustration, not a control algorithm or differential-value derivation. Do not turn the grid into this system: padding a finite terminating grid episode with zeros gives long-run average zero. Keep all five accepted minutes.

**Example 6.2 inside evaluation.** Announce a separate undiscounted five-state random walk, γ = 1, equal left/right probabilities, +1 only on right-terminal entry, all other rewards zero, terminal continuation zero; initialize nonterminal values to 0.5. Explain RMS prediction error against known values, not episode reward. Compare constant-step MC and TD with step sizes identified. The book's right plot averages over 100 runs and shows no uncertainty bands; it cannot establish seed robustness. Ask what further evidence is needed: individual runs/uncertainty, held-out evaluation when true values are unavailable, matched interaction and compute budgets, and controlled step-size/initialization comparisons. Use a noisy curve already in the book; do not fabricate new experimental results. This is a bounded first evaluation activity, revisited later, not a full experimental-methods course in ten minutes.

**Example 6.4 gets eight minutes with its prerequisite.** Distinguish this Example 6.4 (printed 127) from Exercise 6.4 (printed 126). Show the eight episodes and terminal markers, γ = 1. Six of eight departures from B return 1, two return 0, so both batch solutions give `V(B)=0.75`. A was seen once, followed by return zero: batch MC gives `V(A)=0`. Batch TD gives `V(A)=0.75` because observed A transitions lead to B, and B's subsequent behaviour is assumed independent of the route into it. Explain batch increments using a fixed table per pass, then repeated passes with sufficiently small step size; these are not one-pass online answers. TD need not explicitly build a model to share the empirical Markov model's solution. MC fits observed returns; TD pools successor information. Neither answer is certified as the unknown true value. No generic TD superiority or mere bias–variance slogan follows.
