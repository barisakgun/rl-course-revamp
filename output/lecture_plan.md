## Session detail

### 1.1 — RL formulation and information

**Topic groups:** Reinforcement learning formulation, Markov decision processes and related concepts.

**Prerequisite sessions:** Configured entry background.

**Worked activity:** Formulate one running problem; distinguish reward, return, observation and state.

**Pacing:** 20-minute configured syllabus overhead in this slot; defer abstraction theory. Confidence: medium.

### 1.2 — MDPs, returns and values

**Topic groups:** Reinforcement learning formulation, Markov decision processes and related concepts.

**Prerequisite sessions:** 1.1.

**Worked activity:** Compute returns and define a policy/model/value on the running MDP.

**Pacing:** Representation and partial observability remain conceptual. Confidence: medium.

### 2.1 — Bellman equations and evaluation

**Topic groups:** Bellman expectation equations, Bellman optimality equations and related concepts.

**Prerequisite sessions:** 1.2.

**Worked activity:** Derive one expectation backup and perform policy-evaluation sweeps.

**Pacing:** High density; finite examples before operator formalism. Confidence: medium.

**Topic groups:** Bellman expectation equations, Bellman optimality equations and related concepts.

**Pacing:** Protect the improvement argument; asynchronous DP optional. Confidence: medium.

**Pacing:** Average reward uses four previously unallocated minutes and one minute from taxonomy recap. It does not make average-reward algorithms a prerequisite. Confidence: medium.
